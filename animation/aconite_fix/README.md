# ACONITE logo fix

- `letters_fixed.svg`: the letter shapes, cleaned. The cuts where vines and flower lines crossed the letters (most visibly in the N) are filled, and the edges are smoothed.
- `vines_fixed.svg`: the green vines, with small gaps bridged.
- `aconite_original.png`: the original 2D artwork (3000x2300), used for the final hold of the logo shot.

All SVGs share the same 3000x2300 viewBox as the original trace, so they line up with the existing 3D logo.
